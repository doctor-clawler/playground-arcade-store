# Character Grow Game

밝은 마네킹 캐릭터의 피부색과 옷을 꾸미는 단일 캔버스 웹 게임입니다.

## 동작

- 시작 화면에는 제목이나 설명 없이 `시작` 버튼만 표시됩니다.
- 최초 캐릭터는 흰색이며 눈, 입, 옷이 없습니다.
- 오른쪽 사람 아이콘에서 피부색을, 그 아래 옷 아이콘에서 반팔티·긴팔티·겨울코트·바람막이와 옷 색을 고릅니다.
- 새 의상을 고르면 항상 흰색으로 시작합니다.
- `지우개`는 옷을 벗기고, 피부 탭의 `하얗게`는 피부색을 초기화합니다.
- `나가기`는 이번 변경을 버리고, `저장하고 나가기`는 브라우저에 저장한 뒤 시작 화면으로 돌아갑니다.

키보드는 시작 `Enter`/`Space`, 피부 탭 `1`, 옷 탭 `2`, 저장하지 않고 나가기 `Esc`, 전체화면 `F`를 지원합니다.
